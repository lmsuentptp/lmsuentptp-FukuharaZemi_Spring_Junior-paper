# DAO Experimental Economics – Junior Spring Paper (Fukuhara Zemi)

This repository contains my junior-year spring research project at Keio University’s Fukuhara Seminar. The study applies experimental economics and agent-based modeling to explore public goods funding mechanisms in Decentralized Autonomous Organizations (DAOs).

## 📘 Contents

- **Experimental design.ipynb**  
  Outlines the structure of a public goods game with risk-adjusted lottery rewards and NFT/FT incentive mechanisms.

- **DAO version of the code(2)(1).ipynb**  
  Simulates user behavior under varying DAO tokenomics and contribution incentives using Python.

## 🧠 Research Theme

- How do external incentives (like lotteries or NFTs) affect user contributions in DAO fundraising?
- What role does risk preference play in public goods provision within decentralized systems?

## 🛠 Tools Used

- Python, Pandas, NumPy, Matplotlib
- Game Theory, Experimental Design, Agent-Based Simulation
